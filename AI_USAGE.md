# AI Usage

## Overview

AI assistance was used selectively during development of this project.
The final implementation was reviewed and tested locally, including a
complete live execution of the scraping pipeline.

## Areas Where AI Assisted

AI assistance was used for:

-   Structuring the scraper and processing modules
-   Reviewing implementation logic and identifying potential issues
-   Assisting with debugging and test coverage
-   Refining project documentation and submission structure

## Validation

AI-generated suggestions were not treated as a substitute for
verification. The implementation was validated locally through the
project's automated test suite and a complete live pipeline run.

Verified test result:

``` text
88 passed
```

The live run successfully scraped both target websites and generated the
required CSV, JSON summary, and log outputs.

## Human Review

The final project was reviewed by the developer before submission, with
particular attention to:

-   Scraping and pagination behavior
-   Data cleaning and validation
-   Duplicate handling
-   Output generation
-   Error handling and logging
-   Test results

AI assistance was used as a development aid; responsibility for the
final implementation, verification, and submission remains with the
developer.
